🖼️ ClickAndPose.ecu_ferias
ClickAndPose.ecu_ferias es una página web desarrollada y diseñada íntegramente por John Vicente Viejo Loja, fundador del emprendimiento Click & Pose.
Este proyecto representa la identidad digital de un negocio ecuatoriano dedicado a la fotografía instantánea, restauración de imágenes y diseño visual para eventos y ferias.
